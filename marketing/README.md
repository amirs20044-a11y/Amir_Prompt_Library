# Marketing - פרומפטים לשיווק

תיקייה זו מכילה פרומפטים לשיווק דיגיטלי, פרסום, וקידום.

## תתי-קטגוריות מומלצות

- **social-media/** - רשתות חברתיות
- **seo/** - קידום אורגני
- **ads/** - פרסום ממומן
- **email/** - שיווק במייל
- **content/** - שיווק תוכן
- **branding/** - מיתוג

## דוגמאות לפרומפטים

- כתיבת פוסט לאינסטגרם
- יצירת קמפיין פרסומי
- כתיבת מייל שיווקי
- אופטימיזציה ל-SEO
- יצירת לוח תוכן

## טיפים

1. הגדר את קהל היעד בדיוק
2. ציין את הפלטפורמה
3. הגדר את המטרה (מודעות/המרות/לידים)
4. ספק מידע על המוצר/שירות
