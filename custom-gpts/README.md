# Custom GPTs

תיקייה זו מכילה אוסף של Custom GPTs שיצרתי או שאני משתמש בהם.

## איך להוסיף GPT חדש

פשוט הוסף שורה חדשה לקובץ `my-gpts.md` בפורמט:

```
| שם ה-GPT | תיאור קצר | [קישור](URL) |
```

## קטגוריות GPTs

- **Productivity** - פרודוקטיביות ויעילות
- **Coding** - תכנות ופיתוח
- **Writing** - כתיבה ותוכן
- **Research** - מחקר וניתוח
- **Creative** - יצירתיות ועיצוב
- **Business** - עסקים ושיווק
- **Learning** - למידה וחינוך
- **Other** - אחר
