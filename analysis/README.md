# Analysis - פרומפטים לניתוח ומחקר

תיקייה זו מכילה פרומפטים לניתוח נתונים, מחקר שוק, וסיכום מידע.

## תתי-קטגוריות מומלצות

- **data-analysis/** - ניתוח נתונים
- **market-research/** - מחקר שוק
- **competitor-analysis/** - ניתוח מתחרים
- **summarization/** - סיכום מסמכים
- **sentiment/** - ניתוח סנטימנט
- **trends/** - ניתוח מגמות

## דוגמאות לפרומפטים

- ניתוח נתוני מכירות
- מחקר שוק לפני השקה
- סיכום מאמר ארוך
- ניתוח SWOT
- השוואת מוצרים

## טיפים

1. ספק נתונים ברורים ומאורגנים
2. הגדר את השאלות המחקריות
3. ציין את הפורמט הרצוי לתוצאות
4. בקש המלצות מבוססות ניתוח
