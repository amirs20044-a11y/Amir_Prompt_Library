# System - פרומפטים מערכתיים

תיקייה זו מכילה System Prompts ו-Custom Instructions.

## תתי-קטגוריות מומלצות

- **personas/** - אישיויות AI
- **instructions/** - הוראות מותאמות
- **constraints/** - מגבלות והנחיות
- **formats/** - פורמטים קבועים

## מה זה System Prompt?

System Prompt הוא הנחיה שמגדירה את ההתנהגות הבסיסית של ה-AI לאורך כל השיחה.

## דוגמאות

### מומחה טכני
```
אתה מומחה טכנולוגי עם 20 שנות ניסיון.
ענה בצורה מקצועית ומדויקת.
הסבר מושגים טכניים בפשטות.
```

### עוזר כתיבה
```
אתה עורך מקצועי עם רקע בעיתונות.
שפר טקסטים תוך שמירה על קול הכותב.
הצע שיפורים בנימוס.
```

## טיפים

1. הגדר את התפקיד בבירור
2. ציין את הטון והסגנון
3. הוסף מגבלות אם צריך
4. בדוק את ההתנהגות בתרחישים שונים
