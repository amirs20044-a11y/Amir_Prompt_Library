# Templates - תבניות פרומפטים

תיקייה זו מכילה תבניות בסיסיות לבניית פרומפטים איכותיים.

## תתי-קטגוריות מומלצות

- **basic/** - תבניות בסיסיות
- **advanced/** - תבניות מתקדמות
- **chain-of-thought/** - שרשרת חשיבה
- **few-shot/** - דוגמאות מובנות
- **role-based/** - תפקידים

## סוגי תבניות

### תבנית בסיסית
```
[הקשר]
[משימה]
[פורמט פלט]
```

### תבנית מתקדמת
```
[תפקיד]
[הקשר]
[משימה מפורטת]
[מגבלות]
[פורמט פלט]
[דוגמאות]
```

## טיפים

1. התחל מתבנית והתאם אותה
2. הוסף דוגמאות לתוצאה רצויה
3. הגדר את הפורמט בבירור
4. נסה וחזור עד לתוצאה מושלמת
