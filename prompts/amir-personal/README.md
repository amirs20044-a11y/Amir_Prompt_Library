# Amir Personal - מאסטר פרומפט אישי

תיקייה זו מכילה את המאסטר פרומפט האישי של אמיר - המידע הבסיסי שמגדיר את ההקשר האישי לכל האינטראקציות עם AI.

## מטרת התיקייה

מאסטר פרומפט אישי מאפשר ל-AI להכיר אותך טוב יותר ולתת תשובות מותאמות אישית. במקום להסביר כל פעם מחדש מי אתה ומה אתה עושה - הפרומפט הזה עושה את זה בשבילך.

## מה לכלול במאסטר פרומפט

### פרטים אישיים בסיסיים
- שם מלא וכינויים
- גיל / שנת לידה
- מיקום מגורים
- שפות דיבור

### רקע מקצועי
- תפקיד נוכחי / עיסוק
- תחומי התמחות
- ניסיון מקצועי
- השכלה רלוונטית

### תחומי עניין
- תחביבים
- נושאים שמעניינים אותך
- פרויקטים אישיים
- מטרות ושאיפות

### העדפות תקשורת
- סגנון תשובות מועדף (קצר/מפורט)
- שפה מועדפת
- טון (רשמי/ידידותי)
- פורמט מועדף (רשימות/פסקאות)

### הקשר נוסף
- אתגרים נוכחיים
- פרויקטים פעילים
- כלים וטכנולוגיות שאתה משתמש בהם

## תבנית מומלצת

```markdown
# מאסטר פרומפט - אמיר

## מי אני
[תיאור קצר של עצמך]

## רקע מקצועי
[תפקיד, תחומי התמחות, ניסיון]

## תחומי עניין
[תחביבים, נושאים שמעניינים]

## איך אני אוהב לקבל תשובות
[העדפות תקשורת]

## מטרות נוכחיות
[מה אתה מנסה להשיג]

## הקשר חשוב
[מידע נוסף שרלוונטי]
```

## איך להשתמש

1. **צור קובץ** `master-prompt.md` בתיקייה זו
2. **מלא את הפרטים** לפי התבנית
3. **העתק והדבק** בתחילת שיחות עם AI
4. **עדכן מעת לעת** כשהמצב משתנה

## טיפים

- היה כנה וספציפי - ככל שהמידע מדויק יותר, התשובות טובות יותר
- אל תכלול מידע רגיש מדי (סיסמאות, מספרי זהות וכו')
- עדכן את הפרומפט כשיש שינויים משמעותיים בחיים
- צור גרסאות שונות לשימושים שונים (עבודה, לימודים, אישי)
