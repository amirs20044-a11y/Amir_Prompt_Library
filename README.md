# ספריית הפרומפטים של אמיר

ברוכים הבאים לספריית הפרומפטים המאורגנת שלי. ספרייה זו מכילה אוסף של פרומפטים מקצועיים המאורגנים לפי קטגוריות.

## מבנה הספרייה

```
prompts/
├── coding/          # פרומפטים לתכנות ופיתוח
├── writing/         # פרומפטים לכתיבה ועריכה
├── analysis/        # פרומפטים לניתוח נתונים ומחקר
├── creative/        # פרומפטים ליצירתיות ורעיונות
├── business/        # פרומפטים לעסקים ויזמות
├── education/       # פרומפטים לחינוך ולמידה
├── productivity/    # פרומפטים לפרודוקטיביות וארגון
├── marketing/       # פרומפטים לשיווק ופרסום
├── templates/       # תבניות פרומפטים בסיסיות
└── system/          # פרומפטים מערכתיים (System Prompts)
```

## קטגוריות

| קטגוריה | תיאור | שימושים עיקריים |
|---------|-------|-----------------|
| **Coding** | פרומפטים לתכנות | כתיבת קוד, דיבוג, Code Review, ארכיטקטורה |
| **Writing** | פרומפטים לכתיבה | מאמרים, תוכן, עריכה, תרגום |
| **Analysis** | פרומפטים לניתוח | ניתוח נתונים, מחקר שוק, סיכומים |
| **Creative** | פרומפטים יצירתיים | סיעור מוחות, רעיונות, סיפורים |
| **Business** | פרומפטים עסקיים | תכניות עסקיות, אסטרטגיה, ניהול |
| **Education** | פרומפטים חינוכיים | הסברים, שיעורים, מבחנים |
| **Productivity** | פרומפטים לפרודוקטיביות | ניהול זמן, תכנון, ארגון |
| **Marketing** | פרומפטים לשיווק | קופירייטינג, מודעות, SEO |
| **Templates** | תבניות בסיסיות | תבניות פרומפט לשימוש חוזר |
| **System** | פרומפטים מערכתיים | הגדרות אישיות ל-AI, Custom Instructions |

## איך להשתמש

1. **חפש בקטגוריה המתאימה** - כל קטגוריה מכילה פרומפטים קשורים
2. **קרא את תיאור הפרומפט** - כל פרומפט מכיל הסבר על השימוש שלו
3. **התאם לצרכים שלך** - ערוך את הפרומפט בהתאם למשימה הספציפית

## פורמט פרומפט

כל פרומפט בספרייה מאורגן בפורמט הבא:

```markdown
# שם הפרומפט

## תיאור
הסבר קצר על מטרת הפרומפט

## שימושים
- שימוש 1
- שימוש 2

## הפרומפט
[תוכן הפרומפט]

## דוגמה
[דוגמה לשימוש]

## טיפים
- טיפ 1
- טיפ 2
```
