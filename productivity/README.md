# Productivity - פרומפטים לפרודוקטיביות

תיקייה זו מכילה פרומפטים לניהול זמן, תכנון, וארגון עבודה.

## תתי-קטגוריות מומלצות

- **planning/** - תכנון משימות
- **organization/** - ארגון מידע
- **time-management/** - ניהול זמן
- **goals/** - הגדרת יעדים
- **automation/** - אוטומציה
- **templates/** - תבניות עבודה

## דוגמאות לפרומפטים

- יצירת תכנית עבודה שבועית
- ארגון רשימת משימות
- תעדוף לפי מטריצת אייזנהאואר
- יצירת שגרות יומיות
- תכנון פרויקט

## טיפים

1. ציין את המשאבים הזמינים
2. הגדר דד-ליינים
3. ציין עדיפויות
4. בקש תכנית גמישה
