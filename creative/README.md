# Creative - פרומפטים ליצירתיות

תיקייה זו מכילה פרומפטים לסיעור מוחות, יצירת רעיונות, וחשיבה יצירתית.

## תתי-קטגוריות מומלצות

- **brainstorming/** - סיעור מוחות
- **ideation/** - יצירת רעיונות
- **naming/** - שמות ומיתוג
- **storytelling/** - סיפורים
- **design/** - רעיונות עיצוביים
- **problem-solving/** - פתרון בעיות יצירתי

## דוגמאות לפרומפטים

- סיעור מוחות לשמות מוצר
- יצירת רעיונות לסטארטאפ
- חשיבה מחוץ לקופסה
- יצירת קונספטים
- פתרון בעיות בדרכים חדשות

## טיפים

1. אל תגביל את ה-AI - תן לו חופש
2. בקש כמות גדולה של רעיונות
3. ציין קריטריונים להערכה
4. עודד חשיבה לא קונבנציונלית
