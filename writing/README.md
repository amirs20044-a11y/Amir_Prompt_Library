# Writing - פרומפטים לכתיבה ועריכה

תיקייה זו מכילה פרומפטים לכתיבה יצירתית, עריכה, תרגום וכתיבת תוכן.

## תתי-קטגוריות מומלצות

- **content/** - כתיבת תוכן לאתרים ובלוגים
- **editing/** - עריכה והגהה
- **translation/** - תרגום בין שפות
- **copywriting/** - כתיבה שיווקית
- **academic/** - כתיבה אקדמית
- **storytelling/** - סיפורים ונרטיבים

## דוגמאות לפרומפטים

- כתיבת פוסט לבלוג
- עריכה והגהה של טקסט
- תרגום מקצועי
- כתיבת תקציר מנהלים
- שיפור סגנון כתיבה

## טיפים

1. ציין את קהל היעד
2. הגדר את הטון הרצוי (רשמי/לא רשמי)
3. ציין אורך רצוי
4. ספק דוגמאות לסגנון מועדף
