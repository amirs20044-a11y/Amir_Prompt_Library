# Coding - פרומפטים לתכנות ופיתוח

תיקייה זו מכילה פרומפטים הקשורים לתכנות, פיתוח תוכנה וארכיטקטורת מערכות.

## תתי-קטגוריות מומלצות

- **code-generation/** - יצירת קוד חדש
- **debugging/** - איתור ותיקון באגים
- **code-review/** - סקירת קוד
- **refactoring/** - שיפור קוד קיים
- **documentation/** - כתיבת תיעוד טכני
- **testing/** - כתיבת בדיקות
- **architecture/** - תכנון ארכיטקטורה

## דוגמאות לפרומפטים

- כתיבת פונקציה ב-Python
- Code Review מקיף
- המרת קוד משפה לשפה
- כתיבת Unit Tests
- תיעוד API
- דיבוג שגיאות

## טיפים

1. תמיד ציין את שפת התכנות הרצויה
2. הוסף הקשר על הפרויקט
3. ציין מגבלות או דרישות ספציפיות
4. בקש הסברים לצד הקוד
