# Education - פרומפטים לחינוך ולמידה

תיקייה זו מכילה פרומפטים להוראה, הסברים, ויצירת חומרי למידה.

## תתי-קטגוריות מומלצות

- **explanations/** - הסברים ברורים
- **lessons/** - תכנון שיעורים
- **quizzes/** - שאלות ומבחנים
- **tutorials/** - מדריכים
- **simplification/** - פישוט מושגים
- **practice/** - תרגול

## דוגמאות לפרומפטים

- הסבר מושג מורכב בפשטות
- יצירת תכנית שיעור
- כתיבת שאלות למבחן
- יצירת מדריך צעד אחר צעד
- התאמת תוכן לגיל מסוים

## טיפים

1. ציין את רמת הידע של הלומד
2. בקש דוגמאות והמחשות
3. הגדר את הגיל או הרקע
4. בקש בדיקת הבנה
